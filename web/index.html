The scripts need this token so uploading stays behind your login. Set it first — PowerShell: $Env:GETOUT_TOKEN = '…'; shell: export GETOUT_TOKEN='…' — then run the command below. It travels as your session, never on the command line.

On Windows, run Unblock-File .\Upload-File.ps1 after downloading it. Your PowerShell execution policy must permit scripts. If a password is required, the script asks for it; it never appears in the command.

For Linux and macOS. Requires curl, jq, base64, and a SHA-256 tool. Use your file's Linux or macOS path above.

Anyone with the download link (and its password, if set) can download the file without an account. When a link expires, the file is deleted. The service keeps a record of each upload (account, IP address, time, file name, size, checksum) and each visit to a download link (IP address, time, browser, result). GET URLs may appear in network logs; use a service you trust.
